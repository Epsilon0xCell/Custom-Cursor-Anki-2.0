Custom-Cursor-Anki-2.0

The delivery note for the whole project, tucked under the hero bottle: an Anki add-on, copied into the add-ons folder, that adds a Custom Cursor entry to the Tools menu so a student can point Anki at an image file and study under a pointer of their own choosing.

House four, notes left on the step

The three fixes the drawer documents, with their code excerpts kept.

First fix: config is now read for real

The shortcut is taken from config.json and Ctrl+Shift+C is only a fallback for a missing or empty value. From __init__.py, the setup_menu method:

    def setup_menu(self):
        action = QAction("Custom Cursor", mw)
        # I use "or" for the fallback on purpose, not a default value in
        # the get call. A config that holds an empty shortcut string
        # counts as missing for me, and I still want a working shortcut.
        action.setShortcut(config.get("shortcut") or "Ctrl+Shift+C")
        action.triggered.connect(self.show_cursor_dialog)
        mw.form.menuTools.addAction(action)
{
    "default_cursor": "",
    "auto_apply": false,
    "shortcut": "Ctrl+Shift+C"
}

Second fix: no cursor is stranded on the stack

set_cursor restores the previous cursor before pushing a new one, keeping depth at one, and reset pops only when this add-on pushed. From __init__.py, the end of set_cursor:

        if self.current_cursor is not None:
            mw.app.restoreOverrideCursor()

        cursor = QCursor(pixmap)
        mw.app.setOverrideCursor(cursor)
        self.current_cursor = cursor
        return True

Third fix: an unloadable file installs nothing

A null pixmap is refused like a missing path. From __init__.py, the start of set_cursor:

    def set_cursor(self, cursor_path):
        if not cursor_path or not os.path.exists(cursor_path):
            return False

        pixmap = QPixmap(cursor_path)
        # I refuse a file that exists but is not a loadable image. The
        # browse filter offers .cur and .ani, and QPixmap cannot decode
        # those on every platform, so existence is not proof. A null
        # pixmap would install an invisible cursor, which is worse than
        # no change, so I treat it the same way as a missing file.
        if pixmap.isNull():
            return False

The dialog gives two different messages. From cursor_dialog.py, in apply_cursor:

        if not cursor_path or not os.path.exists(cursor_path):
            showInfo("Please select a valid cursor file")
            return
        if not self._manager().set_cursor(cursor_path):
            showInfo("That file could not be loaded as a cursor image")

Note left under a bottle: Please select a valid cursor file. That file could not be loaded as a cursor image. A file can exist and still not load.

5

End of the round, fitting and returns

  1. Copy the folder into the Anki add-ons folder.
  2. Restart Anki.
  3. Open Tools then Custom Cursor or use the shortcut, default Ctrl+Shift+C.
  4. Browse to an image file. PNG, XPM, and JPG are the safe choices.
  5. Press Apply Cursor. Press Reset Cursor to return to normal.

Checked behaviour, kept honest: verified against a stub aqt harness, not inside real Anki.
